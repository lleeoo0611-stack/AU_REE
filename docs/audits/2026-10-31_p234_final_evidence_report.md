## 收斂與重開規則

1. 所有 ID 必須有明確的證據狀態、實質判讀／原生內容依據、缺口與重開條件。未定義的新處置會令重跑失敗，不能自動落入某個「已完成」預設值。
2. 分類完成只表示這一輪有界來源查核收斂。原生資料不足、外部存取受阻、跨專案資源不支持，都是有效且需保留的結果；不可改寫成「沒有 REE」或靜默排除。
3. 沒有新公開入口、原檔或證據改變時，不再反覆請求同一失敗 URL。取得可驗證原件、source-scoped 礦權／地理／資源資料或出版者恢復服務時，按固定 ID 重開。
4. Project／C1／JORC 核准與 13 案 Gate、MCDA 仍暫緩。任何明確 REE 主張均不能藉本次分類繞過核准。沒有新增簽章或排名。
