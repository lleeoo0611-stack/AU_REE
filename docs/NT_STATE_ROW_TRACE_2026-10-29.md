# 北領地逐列來源查核進度（2026-10-29）

## 固定母體列級狀態

本輪在保留487筆凍結 target ID 的前提下，新增北領地個案來源判讀並重建派生表。全體最新列數：37 `PROJECT_CANDIDATE_REVIEW`、6 `HOLD_REE_ROLE`、444 `HOLD_INSUFFICIENT_PROJECT_IDENTITY_OR_REE_ROLE`；NT 本身為3列候選、52列 HOLD。候選專案分組表為29組。以上是列級/暫定狀態，不代表外部資料已完成487筆全查，也不代表29組均為最終Project數。未排除任何列，未執行MCDA。
